# רשימת קניות חכמה - פרויקט לדוגמה

זהו פרויקט הפתיחה לתרגיל "מהרעיון לאפליקציה עובדת" בקורס Claude Code למתחילים.

## איך משתמשים בזה?

1. פתח את התיקייה הזו כפרויקט חדש ב-Claude Code Desktop
2. תן ל-Claude Code לקרוא את `CLAUDE.md` ו-`spec.md` (הוא יעשה זאת אוטומטית)
3. השתמש בפרומפט הפתיחה מ-`spec.md` כדי להתחיל לבנות
4. אחרי כל שינוי - עדכן את `spec.md` אם ההסכמה על הפרויקט השתנתה

## מבנה הקבצים

| קובץ | מטרה |
|---|---|
| `CLAUDE.md` | הנחיות קבועות ל-Claude Code על איך לעבוד בפרויקט הזה |
| `spec.md` | מסמך ההסכמה - מה בונים, מה לא, ומה עתידי |
| `PROGRESS.md` | מעקב התקדמות - מתעדכן תוך כדי העבודה |

זהו פרויקט לדוגמה שנועד ללימוד. שנה כל דבר - שם, קטגוריות, עיצוב - כדי שירגיש שלך.
